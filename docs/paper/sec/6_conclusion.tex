\section{Conclusions and Future Work}
\label{sec:conclusion}

For all transformations studied except \verb|Mirroring|, both DeepGaze IIE \cite{deepgazeiie} and UNISAL \cite{unisal} models perform worse than the untransformed set of images on average. Increasing the intensity of the transformation leads to further performance loss. Performance loss is measured relative to the real map and center bias, and so losses are not attributable to destruction of information content due to the transformation.

We fail to find any computable indicator which correlates with performance loss. Gathering gaze distribution data from human trial currently remains the only way to verify whether performance loss occurs for an arbitrary transformation.

Our work argues that current state-of-the-art gaze prediction models cannot be confidently applied to many forms of visual media. We have demonstrated performance loss with many common digital image transformations. For example, if a visual media producer wished to compress an image in a similar way to the compression transformations we've studied, they can expect a minimum of ten percent performance loss. For pathological cases, our studies show that transformations may produce up to $95\%$ performance loss. These losses might bring the noise-to-signal ratio high enough that gaze prediction applications become unhelpful.

Generally, our work concludes that, to the extent that CAT2000 \cite{cat2000} and similar gaze prediction datasets are representative of image classes of interest to an arbitrary application, we have shown that performance will degrade for those image classes when common digital image transformations are applied. Unfortunately, if we assume that CAT2000 is not representative of an application's image classes, there is almost no data to show how well the models will perform for those image classes. Either way, if digital image transformations are involved, confidence in performance remains low.

For future work, we would like to test a greater number of transformations, including distortions, color manipulations, stylistic filters, and compositions of all the above. We would also like to test transformations with more rigorous definitions of "intensity", at a granular level such that we can more accurately elucidate trends in performance as we increase the intensity of transformations. Finally, we might conduct a more thorough search for indicators of performance loss by testing correlation for a greater amount of independent variables.

The code for model inference, metric computation, and visualization; along with tabular data saving all computed results; will be made pubicly available in a repository online. The repository will be referenced in the deanonymized version of this paper.
